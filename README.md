# QUE PALTA — Android 2.1

Paquete Android del prototipo Que Palta: misiones sociales, mapa esquemático, lector QR, progreso local en SQLite y diario personal.

## Publicar el APK 2.1

1. Descarga el archivo `QuePalta_Android_Source_v4.zip` generado en esta conversación.
2. Súbelo sin descomprimir a la raíz de este repositorio, conservando ese nombre.
3. Pulsa **Commit changes**. GitHub Actions iniciará la compilación.
4. Cuando termine en verde, abre **Releases** y descarga `app-debug.apk` del release más reciente.

- [Ejecuciones de compilación](https://github.com/Carhuamaca/QUEPALTA/actions)
- [Descargar versiones publicadas](https://github.com/Carhuamaca/QUEPALTA/releases)

## Alcance

El avance se guarda localmente en SQLite. El inicio de sesión UPC, las cuentas, la sincronización entre celulares y la administración remota están pendientes. Los retos grupales permiten compartir invitaciones, pero cada teléfono guarda su propio progreso. El croquis es orientativo y no está a escala. Esta aplicación es un prototipo académico independiente, no una aplicación oficial de UPC.
